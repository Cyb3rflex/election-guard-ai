# AI-Based Detection Documentation
## Isolation Forest for Election Network Anomaly Detection

### Algorithm: Isolation Forest
- Unsupervised machine learning algorithm
- Detects rare events (anomalies) by isolating points in feature space

### Features Used:
- request_rate
- port_diversity
- traffic_spike
- byte_spike
