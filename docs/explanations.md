# Explainable Alert System

## Purpose
Security alerts are often difficult for non-technical stakeholders to understand.
This module converts technical detections into clear, human-readable explanations.

## How It Works
1. Rule-based alerts identify known suspicious patterns
2. AI-based detection identifies unknown or rare behavior
3. Both outputs are merged into a unified alert
4. An explanation engine generates natural-language reasons

## Example Explanation
"Unusually high request rate detected; Access to multiple ports; AI model identified unusual behavior pattern"

## Teaching Value
- Helps students understand *why* an alert was triggered
- Demonstrates explainable AI principles
- Improves decision-making for election officials

## Impact
Clear explanations reduce response time and prevent alert fatigue.
